# LLM 批量测试脚手架

> 一个双击就能跑的「用 Python 调大模型 API 做批量测试」脚手架。
> 不用写代码，也不省掉工程 —— 把该有的重试、续跑、落盘、预检全做进去了。

给会一点 Python、但不想从零搭工程的人用：产品经理、运营、分析师。
典型任务是**把一批文本批处理**——500 条车主评论打标签、客服工单批量摘要、
竞品更新日志提功能点、给一批功能批量生成文案。

---

## 为什么需要它

写个 `for` 循环调 API 只要 15 行。真正花时间的是剩下那 400 行：

| 你会遇到的问题 | 这个项目怎么处理 |
|---|---|
| 跑 500 条，中途网络抖一下，前面结果全丢 | **边跑边落盘**，每完成 1 条就写一次，中断最多丢 1 条 |
| 16 条里有 7 条被限流，得手工补 | **失败重试**（指数退避）+ **断点续跑**，重跑只补没成功的 |
| 重跑一遍，已成功的又调一次，重复烧钱 | **断点续跑**靠 `uid` 精确跳过已成功的记录 |
| Key 填错，16 条全跑一遍、每条还退避重试，干等两分钟 | **开跑前预检 1 条**，致命错误立即停批并告诉你怎么修 |
| 跑完 500 次调用，才发现结果文件被 Excel 锁着写不进去 | **开跑前探测文件可写**，被占用就停，一分钱不花 |
| 试跑结果和真跑结果混在一起，分不清哪个是模型真写的 | **试跑用独立文件名 + 独立状态值**，两者永不混淆 |

**一句话**：门槛不在「调 API」，在「让它稳定跑完 500 条、还不重复烧钱」。

---

## 特性

- **双击就能跑** —— 3 个 `.cmd` 入口，不需要命令行、不需要配环境（首次自动建 `.venv` 装依赖）
- **试跑不花钱** —— `--dry-run` 不需要 API Key，第一天就能看到完整流程跑通
- **免费模型可用** —— 默认接智谱 `glm-4.7-flash`（永久免费，200K 上下文）
- **一套 SDK 通吃多平台** —— 走 OpenAI 兼容协议，换平台只改一个 `base_url`
- **错误分类** —— 401/403/404/400 判定为致命错误立即停；429/超时/5xx 才退避重试
- **A/B 对照内置** —— 同一道题出 A/B 两版提示词，跑完按 `variant` 分组看差异
- **原始数据一键生成用例表** —— 500 条评论自动套进提示词模板，不用手工拼
- **零依赖哲学** —— 除 `openai` 外全用标准库，自己写 12 行 `.env` 解析器，少一个依赖少一个坑
- **中文不乱码** —— 读写均用 `utf-8-sig`，Excel 双击直接打开
- **三份中文文档** —— 结构解析 / 逐行注释 / 可复用学习笔记

## 快速开始

### 方式一：双击（推荐）

```
1-先试跑.cmd        不花钱、不用 Key，只验证流程通不通（output 列是假答案）
2-真跑.cmd          填好 Key 后双击，output 列才是模型真写的
3-生成用例表.cmd     把你自己的一批文本套进提示词模板，生成用例表
```

首次双击 `2-真跑.cmd` 会自动建虚拟环境并安装 `openai`，之后不再需要。

用之前把 `.env.example` **复制**成 `.env`（是复制，不是改名），填上 Key。

### 方式二：命令行

```bash
# 试跑：不花钱，验证流程
python 02_batch_test.py --input prompts.csv --output results_试跑.csv --dry-run

# 真跑但先只跑 5 条，确认花的是自己以为的钱
python 02_batch_test.py --input prompts.csv --output results.csv --limit 5

# 全量（免费额度建议 4 并发）
python 02_batch_test.py --input prompts.csv --output results.csv --workers 4
```

### 用自己的数据

```bash
# 500 条评论 → 500 行用例表
python make_prompts.py --input comments.txt --template-a 模板A.txt --out prompts.csv

# A/B 抽样：随机抽 30 条 × 2 版，先选出更准的提示词，再跑全量
python make_prompts.py --input comments.txt --template-a 模板A.txt \
    --template-b 模板B.txt --sample 30 --out prompts_ab.csv
```

数据格式：`.txt` 一行一条；`.csv` 需表头，用 `--text-col 列名` 指定列（支持中文列名）。
模板就是普通文本文件，**留一处 `{评论}`** 表示内容插在哪。
